# jeedom-plugin-googletvbe

Plugin Jeedom pour piloter les téléviseurs Google TV / Android TV en réseau
local, en PHP natif (Google Cast, télécommande Android TV, Wake-on-LAN),
et garder en marche l'appli TvOverlay du plugin frère
[TvOverlay](https://github.com/replicatorbe/jeedom-plugin-tvoverlaybe).

- Documentation : [docs/fr_FR/index.md](docs/fr_FR/index.md)
- Tests hors ligne : `php tests/run.php`
- Contrôles contre le cœur installé : `php tests/check-classes.php`
